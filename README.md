# Titulo del Proyecto: Asistente empresarial ASG

Este proyecto de software consiste en dar solucion a un reto de hackatec,  
evento organizado por el TecNM campus Pachuca que es la sede.

La problematica a resolver se encuentra detallada en el pdf adjunto:  
Reto HackaTec Nacional 2025_SWI.pdf

Este proyecto consta de varios micro retos cada uno resuelto con n8n y almacenado en su propio contenedor.

Todos los contenedores se ponen en funcionamiento utilizando CI/CD, github Actions hacia un VPS de Hostinguer.
